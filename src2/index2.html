분기 · 5트랜치 · 원본(당진 FS) 대조 검증 완료 엔진

엔진 v2 — 계산 정확도 검증 완료
이 화면은 기능 검증용 1차 버전입니다. 상환방식은 원금균등(1)/원리금균등(2)만 입력 가능합니다.
64회차 직접 키인(방식 3)은 아래 "당진 FS 불러오기"로만 채워집니다(직접 입력 UI는 아직 없음). 기본값(빈 폼)으로 그냥 생성을 누르면 당진 실측치와 다른 숫자가 나옵니다 — 당진 원본과 동일한 숫자를 보려면 반드시 "당진 FS 불러오기"를 먼저 누르세요.
1

사업 기본 가정

2

사업자 구성 (지분)

자본금(자본금 항목의 총액)을 여러 출자자가 나눠 낼 때 이름과 지분율을 입력합니다. 지분율 합은 100%여야 하고, 모든 출자자는 각자 지분율만큼 자본금 납입·배당 수령을 동일한 타이밍에 비례로 나눠 갖는다고 가정합니다.
3

공사비 지출 곡선

공사기간(분기)마다 실제 얼마씩 돈이 나가는지 입력합니다. 보통 공사 초반·후반에 몰리는데, 잘 모르면 균등분배로 두면 됩니다. DSRA는 준공분기에 별도로 조달돼서 여기 포함 안 합니다.
4

차입 트랜치 (자본금 + 선순위 A~D + 후순위)

보통 선순위 트랜치 1~2개만 채우고 나머지는 금액 0으로 두면 됩니다. "투입순서"가 같은 트랜치는 금액 비례로 동시에 인출됩니다. 트랜치 조건을 잘 모르면 "간편설정"으로 부채 전액을 표준 조건 하나로 묶어서 대략적인 결과부터 볼 수 있습니다.
투입순서: 숫자가 작을수록 먼저 인출(1=가장 먼저) · 거치: 원금 상환 없이 이자만 내는 기간(년) · 상환: 거치 이후 원금을 갚아나가는 기간(년) · 방식: 원금균등(매기 동일 원금) / 원리금균등(매기 동일 총상환액)
5

민감도 분석

Base는 위 "사업 기본 가정" 값을 그대로 참조하는 기준행 — 불러오기 버튼으로 그 순간의 입력값을 채웁니다. Case는 판매단가·총사업비·운영비·금리를 직접 입력해서 Base와 비교하는 행이고, 더 필요하면 "+ 시나리오 추가"로 늘리면 됩니다. "당진 FS 불러오기"로 채운 상태에서는 실측치가 고정돼 있어 민감도 분석이 의미 없습니다 — 일반 입력(프리셋 미사용) 상태에서만 쓰세요.
