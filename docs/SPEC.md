## 3. 건설이자(IDC) 규약 — 검증 완료

```
IDC(t) = (직전 기말까지의 누적 인출액) × 금리 ÷ 기간수
```

- 인출은 **기말 시점** (인출 당기에는 이자가 붙지 않음)
- 이자는 **기초잔액**(= 직전 기말 누적 인출) 기준
- 분기는 정확히 `÷4`. **해당 분기의 월수와 무관** (2024-06-30은 1개월짜리
  건설분기지만 그래도 1/4)
- **건설이자는 이자부 잔액에 자본화하지 않습니다.** 별도로만 누적됩니다.
  (자본화하면 2024-12-31 IDC가 221.04가 되는데 원본은 219.09)

검증 (선순위A, 5.6%):

| 기말 | 기초잔액 | IDC |
|---|---|---|
| 2024-09-30 | 9,935.16 | 139.09 |
| 2024-12-31 | 15,649.53 | 219.09 |
| 2025-03-31 | 26,980.33 | 377.72 |
| 2025-06-30 | 38,474.19 | 538.64 |
| 2025-09-30 | 50,000.00 | 700.00 |
| **합계** | | **1,974.55** |

IDC 합계 A 1,974.549 / B 1,939.290 / C 17.340 → **3,931.179**

원본은 순환참조를 `Funding!E55 건설이자(값)` 하드코딩으로 끊습니다.
JS에서는 반복수렴으로 풀고, 엑셀 출력 시에는 값을 굽고 검증 셀을 답니다.

   철거비 2,000과 금융수수료 320을 유입에서 차감합니다.
   v1은 유출에 IDC를 포함하고 금융수수료가 없어서, 서로 반대 방향의 두
   오차가 우연히 상쇄돼 8.46% vs 8.42%로 "비슷해 보였습니다".
   **v2는 원본 정의를 그대로 따르세요.**

   트랜치의 미사용 셀이니 무시하세요.
